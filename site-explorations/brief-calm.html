Charrette · Brief · September 2026

Agents come and go. The project stays.

Charrette gives a software project a memory it owns and a coordinator that moves the work between AI agents, so developers stop acting as the go-between. It works with any agent, any model and your own subscriptions, on your own servers.

1 · The problem

Agents can now do real engineering work. The way we run them hasn’t caught up.

Coding agents plan, implement, test and respond to review. Serious teams already use several, because the best one changes every few months. But the workflow around them is still a set of chat windows, and it breaks in two places.

Problem A

The project has no memory of its own.

Why a decision was made, what was already tried, which constraint came from a customer: that knowledge is scattered across tools and heads. Change agents and most of it stays behind.

Problem B

The developer is the message bus.

An agent finishes. Someone has to notice, collect the diff, brief a reviewer, route the finding to a repair, start the tests. The agents run in parallel. The developer’s attention does not.

2 · The product

A memory the project owns, and a coordinator that uses it.

Project memory

Not a docs folder. A record of what the project believes, and how sure it is.

  • Every claim has a standing: canonical, observed once, proposed, or retired.
  • Every claim has provenance: which task produced it, and how.
  • When two claims disagree, both stay visible until someone decides.
  • Any agent is briefed from it. None of it lives inside an agent.

Coordinator

Most “agent orchestration” starts a sub-agent and waits. Charrette decides what happens next.

  • Routes each step to the right agent and model, including a reviewer from a different lab than the author.
  • Grows the plan from evidence: a finding adds a repair, a sensitive file adds a security audit.
  • Checks that done means tested and reviewed, not an agent’s own summary.
  • Asks you only when the decision is genuinely yours.
1DelegationOne agent starts another and waits for text back
2Parallel agentsMany sessions at once; you carry context between them
3Fixed pipelineThe same steps every time, whether needed or not
4Graph from evidenceEach result decides the next step
5SupervisionThe graph, plus routing, an attention boundary, and memory

Most tools sold as orchestration today sit on rungs 1–3. Charrette is built for 4 and 5.

4 · The market

Everyone is building this layer, each for their own agent.

The largest players in AI coding are all moving from the agent to the project around it: persistent knowledge, cloud tasks, review flows and multi-agent coordination. That validates the category. But each ties the project’s memory to what it sells, whether that’s its agent, its models, its compute or its platform.

For each vendor, that’s rational. A memory that moves cleanly to a competitor stops keeping customers. For the engineering team it’s the wrong trade, because the tools churn faster than the project does. The best coding model has changed hands repeatedly in the last eighteen months, and prices swing just as often. Teams that tie their context to one tool pay for it at every switch.

The market rewards loyalty to a project’s context and punishes loyalty to any one tool. Charrette is the neutral place to keep that context.

5 · Why open wins

An engineering lead choosing where project knowledge lives is choosing for years.

Own the memory

Plain files in an open format, on your disk or your servers. Leave any time and take all of it with you.

Own the version

Self-host, pin or fork. The tool that runs your engineering process doesn’t change under you mid-quarter.

No training incentive

We don’t sell models or compute. Your project’s knowledge is nobody’s training data, and we have no reason to want it.

Frontier models at subscription prices

Charrette runs the official agent tools a team already pays for, rather than reselling API tokens at a markup.

And one thing no vendor can offer: independent review. Having a different lab’s model check the work is one of the strongest quality controls available, and no lab will sell you an independent reviewer of its own model.

6 · The business

Charge for coordination, never for compute.

Charrette doesn’t resell model access. Teams bring their own agents and spend, and pay for what no single agent gives them: a shared project record, sync, governance and support. That makes Charrette an addition to an existing AI budget rather than a replacement for it, and keeps us out of a price war with the model labs.
