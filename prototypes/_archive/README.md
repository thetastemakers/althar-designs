# Archived shell explorations

Five directions were built for the persistent shell question. Direction 5,
Rooms, became the baseline on 20 September 2026; the rest are kept here as
the record of what was tried and rejected, not as live code. Nothing in this
folder is imported by the prototype.

- `directions/Record` — the project as one continuous, append-only record.
- `directions/Console` — the project as a running machine, three fixed zones.
- `directions/Address` — no navigation; a written brief and one address line.
- `directions/Standup` — one conversation and a board sharing the window.
- `Picker.jsx` / `Picker.css` / `index.js` / `App.jsx` / `App.css` — the
  harness that presented the five directions side by side.
- `Icon.jsx` — the full icon set as it stood; the live set is pruned to what
  the product actually draws.
